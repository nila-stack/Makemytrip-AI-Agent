# Myra Trip Rooms · MakeMyTrip concept prototype

Razorpay Design × NID assignment. React + TypeScript + Vite. All AI responses, prices and friends are simulated.

## Deploy on Vercel
1. Push this folder to a GitHub repo (or run `npx vercel` inside it).
2. In Vercel: Framework preset **Vite**, build command `npm run build`, output directory `dist`.

## Local
npm install
npm run dev

`?view=mobile` opens the phone-only experience (the QR code on desktop points there).
